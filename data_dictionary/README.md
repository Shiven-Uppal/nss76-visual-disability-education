# Variable dictionary

Add a file named `variable_dictionary.csv` or `variable_dictionary.md` here before release. It should document every source and constructed variable used in the manuscript.

Recommended fields:

| Field | Description |
| --- | --- |
| Analysis variable | Name used in the code |
| Source field | NSS-76 field name(s) |
| Definition | Exact analytic definition |
| Coding | Included values and exclusions |
| Population | Eligible respondents |
| Used in | Table, figure, or model |

Do not reproduce restricted microdata records or disclose information that would enable reconstruction of individual records.
