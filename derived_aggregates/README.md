# Derived aggregate estimates

This directory is for public, non-disclosive aggregate outputs only. Before release, include the aggregate estimates used in the manuscript, such as:

- analytic sample counts;
- weighted common-support coverage;
- standardised probabilities by reported intervention status;
- adjusted percentage-point differences and PSU-bootstrap intervals;
- age-stage occupancy estimates; and
- sharp transition-bound summaries.

Every table should identify its script of origin and state that it contains no unit-level NSS-76 data.
