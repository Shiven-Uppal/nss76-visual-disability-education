# Analysis code

Place the reproducible analysis scripts in this directory. Use ordered filenames so that the workflow is transparent, for example:

1. `01_import_and_clean.R`
2. `02_construct_variables.R`
3. `03_standardised_association.R`
4. `04_markov_bounds.R`
5. `05_sensitivity_analyses.R`
6. `06_tables_and_figures.R`

Do not include raw NSS-76 files, access credentials, or unredacted logs in this directory or elsewhere in the repository.
